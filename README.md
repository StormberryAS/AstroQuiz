# AstroQuiz

Test your astronomical knowledge with fun, randomised multiple-choice trivia. Part of the [Stormberry Labs](https://stormberry.as/labs.html) ecosystem.

## Features
- 10 randomised questions per round from a curated question bank
- Immediate visual feedback with explanations for every answer
- High score tracking via `localStorage` — no server, no cookies
- Glassmorphism UI with smooth card animations
- Fully offline-capable after first load

## Architecture
- **Vanilla HTML/CSS/JS** — no frameworks, no build step
- **Privacy first** — zero external requests, zero tracking
- **Sovereign AI** — built and maintained using high-speed agentic workflows
